# Retail-Industry-Promotions-sales-analysis
Analyzed retail sales data using SQL Server to evaluate promotion effectiveness. Calculated Incremental Revenue (IR) and Incremental Sold Units (ISU) and analyzed store, city, product category, and promotion-type performance. Identified top and underperforming stores and measured revenue and sales contributions. Used CTEs, JOINs, aggregate functions, and Window Functions such as ROW_NUMBER and DENSE_RANK to generate actionable business insights.

Skills
SQL Server, SQL, CTEs, JOINs, Aggregate Functions, Window Functions, ROW_NUMBER, DENSE_RANK, Data Analysis, Retail Analytics, Business Insights
